🧭 Introduction to Kubernetes
-----------------------------------------------------------------------------------------------------------------------
Kubernetes is an open-source container orchestration platform that automates the deployment, scaling, and management of containerized applications.

With Kubernetes, you define how your application should run in a YAML configuration file — such as how many containers you want and where they should run.

Kubernetes then automatically maintains that desired state, keeping your applications running at the required scale.
It also provides self-healing capabilities — if a container fails, Kubernetes automatically restarts or replaces it.

💡 Orchestration platform means a system that automatically manages the lifecycle of containers — including their creation, scheduling, scaling, and deletion — without manual intervention.
